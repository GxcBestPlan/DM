# frontend

DM 前端：Vite 8 + Vue 3.5 + vue-router 4，包管理器 npm。无 UI 框架、无状态库。

## 本地开发

```sh
npm install      # 安装依赖
npm run dev      # 开发服务器（http://localhost:5173，/api 代理到 8080）
npm run build    # 生产构建（输出 dist/，可静态托管）
npm run preview  # 预览构建产物
```

联调顺序：先启动 MySQL 与后端（见 `../backend/README.md`），再 `npm run dev`；
需要演示数据时执行 `../scripts/seed-demo.sh`（会打印各角色账号）。

## 设计语言：调度台

这套界面刻意避开通用 SaaS 卡片风，走"控制室调度台"的仪器感：**结构靠分隔线与对齐，颜色几乎只用于状态信号**。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#16202b` | 正文、主按钮、强分隔 |
| `--surface` | `#edf1f4` | 工作台底色（冷灰，非暖米色） |
| `--panel` | `#ffffff` | 工作面板 |
| `--rule` / `--rule-soft` | `#c9d5de` / `#e1e8ed` | 结构线 |
| `--live` | `#0b7285` | 进行中 / 当前 / 可点击焦点 |
| `--queue` | `#a86413` | 等待类状态（待评审、待测试） |
| `--risk` | `#a32b22` | 阻塞、插队、超载 |
| `--done` | `#1d6b45` | 已验收 / 已完成 |

- **字体**：单一无衬线族（system-ui → Segoe UI → PingFang SC → Microsoft YaHei），数字统一 `tabular-nums`；个性来自尺度对比与字重，不引外链字体（内网部署，中文优先）。
- **形状**：圆角只有 2px，用在不该有尖锐边缘的输入框/芯片上；不用阴影堆卡片。
- **记忆点**：`components/BeatStrip.vue` —— 迭代节拍轴。十个工作日一格，已过格填充、当天为青色，登录页用它做唯一的一次性动效，看板/顶部/报表趋势复用同一元素。
- **文案**：按钮写动作结果（"排入迭代"→ 提示"已排入"），空状态给下一步动作，错误直接说原因与修法；不用 `·` 拼接元信息、不给按钮加箭头、不用全大写标签。

## 结构

```
src/
├── main.js / router.js        # 入口与路由（hash 模式，静态托管无需服务端 rewrite）
├── api.js                     # fetch 封装：自动带 token、统一错误信息
├── session.js                 # 登录态（token + 当前用户），无 pinia
├── store.js                   # 迭代上下文（顶栏/看板/管道/报表共用）
├── labels.js                  # 状态、类型、角色的中文标签与色调
├── ui.css                     # 设计令牌与基础组件（面板/表格/按钮/芯片/对话框…）
├── App.vue                    # 外壳：左侧导航（按角色显隐）+ 顶栏（小队/迭代/节拍轴）
├── components/
│   ├── BeatStrip.vue          # 迭代节拍轴（含 compact 与 dark 变体）
│   ├── StatusChip.vue         # 状态芯片（按 labels 映射中文与色调）
│   └── TaskActions.vue        # 任务更新（开始/完成/备注/阻塞），工作台与我的任务共用
└── views/                     # 12 个页面，与需求文档 §9 一一对应
```

## 权限与页面

菜单按角色显隐，路由守卫做二次校验（`router.js` 的 `canAccess`）；后端仍是最终裁决者，越权请求返回 403。

| 角色 | 可见页面 |
|---|---|
| 产品经理 | 工作台、需求池、迭代看板、需求详情、统计报表 |
| 开发管理者 | 工作台、迭代管理、迭代看板、管道排期、我的任务、测试工作台、统计报表 |
| 开发 | 工作台、迭代看板、我的任务 |
| 测试 | 工作台、迭代看板、需求详情、测试工作台 |
| 跨队管理 | 跨队总览、迭代看板/管道（只读）、统计报表 |
| 系统管理员 | 全部 + 组织管理 |
